### 2. Rendering Pipeline

```mermaid
flowchart TD
    A[Textbook Context & User Prompt] --> B(Gemini Model)
    B --> C[storyboard.json generated]
    C --> D(Sarvam AI TTS API)
    D --> E[scene_*.wav synthesized]
    C & E --> F[Copy to hyperframes_test_app/outputs/vl_id/]
    F --> G(node run-storyboard.js)
    G --> H[Stitches HTML & GSAP scripts into index.html]
    H --> I{Hyperframes CLI}
    I -->|1. preview| J[Localhost Development Server]
    I -->|2. render| K[Puppeteer Headless Frame Capture]
    K --> L[FFmpeg encodes frames and WAV audio into output.mp4]
```

1.  **Generation Phase**:
    *   Textbook query context is retrieved. Gemini processes this context and designs a structured storyboard JSON containing scenes, visual descriptions, scripts, and template hints.
    *   Voiceover narration files (`.wav`) are generated via Sarvam AI TTS for each scene based on the text scripts.
2.  **Compilation Phase**:
    *   [`run-storyboard.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/run-storyboard.js) is executed.
    *   It parses the storyboard JSON and loops through the scenes, mapping each scene's `template_id` to its corresponding JS module in the `templates/` folder.
    *   The script calls `template.render()` to get the raw HTML layout and then calls `template.animate()` to fetch the GSAP script blocks.
    *   These HTML sections and GSAP timeline segments are output into a single unified file: `index.html`.
3.  **Preview / Capture Phase**:
    *   **Preview**: The `hyperframes preview` command launches a local dev server with browser-based playback controls.
    *   **Render**: The `hyperframes render` command runs a headless browser (Puppeteer) to load `index.html`, step through the timeline frame-by-frame, capture high-quality frame screenshots, and combine them with the `.wav` audio files using FFmpeg to output the final MP4.

### 4. How JSON Flows into Rendering

1.  **JSON Structure**: The JSON structure follows this format:
    ```json
    {
      "lesson_title": "Structure of Water",
      "theme": "Science",
      "scenes": [
        {
          "scene_no": 1,
          "template_id": "illustrated_scene",
          "teacher_script": "This is a water molecule...",
          "template_data": { "elements": [...] }
        }
      ]
    }
    ```
2.  **HTML Compilation**: [`run-storyboard.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/run-storyboard.js) maps the JSON:
    *   Scene start times and durations are computed dynamically.
    *   Each scene has its layout built by calling `templates[template_id].render(scene_no, template_data)`.
    *   The narration script is written into a `.subtitles-container` div.
    *   Audio elements are appended: `<audio class="clip" data-start="..." data-duration="..." src="./scene_no.wav"></audio>`.
3.  **Runtime Initialization**: Inside `index.html`:
    *   The global `theme` properties (`background`, `fontFamily`, colors) are loaded dynamically based on the JSON’s `theme` using helpers in `theme.js`.
    *   KaTeX loads and compiles any LaTeX math formula fields in the background.
    *   A single master timeline is created: `const mainTimeline = gsap.timeline();`.
    *   Sequential script blocks from each template's `animate()` function are appended to `mainTimeline`:
        ```javascript
        mainTimeline.add(sceneTl, sceneStart);
        ```
    *   This timeline object is exposed to Hyperframes on `window.__timelines["root"]`.

*   If `scene.template_id` is missing or invalid, it defaults to `GeneralScene.js`.

### 10. Which Framework is Used Internally

*   Hyperframes **does not** use heavy modern client frameworks like React, Remotion, or Motion internally to structure the composition page.
*   It is a **Vanilla HTML5, CSS3, and JavaScript (GSAP-based) framework**.
*   The **Hyperframes CLI** uses two key open-source technologies under the hood:
    1.  **Puppeteer** (Headless Chromium): Loads the compiled `index.html` page and steps through the timelines frame-by-frame, capturing screenshots at the configured frame rate.
    2.  **FFmpeg**: Stitches these frame screenshots and audio files together to render the final deterministic, high-quality MP4 file.

### How a Template is Selected by the Renderer

The rendering orchestrator [`run-storyboard.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/run-storyboard.js) maps the JSON storyboard structure (`lesson.json`) to dynamic browser pages through the following mechanism:

1.  **Registry Mapping**: The compiler holds a static map of allowed template IDs to local modules:
    ```javascript
    const templates = {
      title_slide: require('./templates/TitleSlide'),
      concept_diagram: require('./templates/ConceptDiagram'),
      cycle_template: require('./templates/CycleTemplate'),
      math_derivation: require('./templates/MathDerivation'),
      column_comparison: require('./templates/ColumnComparison'),
      horizontal_timeline: require('./templates/HorizontalTimeline'),
      database_grid: require('./templates/DatabaseGrid'),
      venn_diagram: require('./templates/VennDiagram'),
      taxonomy_tree: require('./templates/TaxonomyTree'),
      cartesian_grid: require('./templates/CartesianGrid'),
      geo_marker: require('./templates/GeoMarker'),
      before_after_slider: require('./templates/BeforeAfterSlider'),
      quiz_checkpoint: require('./templates/QuizCheckpoint'),
      illustrated_scene: require('./templates/IllustratedScene'),
      image_scene: require('./templates/ImageScene'),
      general_scene: require('./templates/GeneralScene'),
    };
    ```
2.  **Resolution Loop**: For every scene defined in the input JSON, the engine reads its `template_id` value.
3.  **Module Resolution**:
    *   **Direct Rendering**: If a matching key exists in the registry, the corresponding template object is loaded.
    *   **Delegated Fallbacks**: Several specialized templates (`taxonomy_tree`, `cartesian_grid`, `geo_marker`, `before_after_slider`) delegate inside their respective files to [`GeneralScene.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/templates/GeneralScene.js) by calling `module.exports = GeneralScene;`.
    *   **Fallback Default**: If the `template_id` is missing, null, or unknown, the compiler defaults to the fallback [`GeneralScene.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/templates/GeneralScene.js).
4.  **Composition Ingestion**: The compiler calls the two functions exported by the chosen template:
    *   `template.render(scene_no, template_data, storyboard)`: Generates raw HTML strings which are appended to a main `<div class="composition">` element inside `outputs/<lesson_id>/index.html`.
    *   `template.animate(scene_no, template_data, null, scene_duration)`: Generates GSAP animation command strings which are stitched sequentially into a single timeline: `mainTimeline.add(sceneTl, sceneStart)`.

### Detailed Template Architectures

#### 1. Title Slide ([`TitleSlide.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/templates/TitleSlide.js))
*   **Intended Purpose**: Introduces the lesson topic at the beginning of a lesson (opener).
*   **Supported Scene Types**: Introductory scene.
*   **Configurable Properties**:
    *   `title` (string): Primary large heading text.
    *   `subtitle` (string): Secondary explanatory summary.
*   **Supported Animations**:
    *   Icon card zoom-in pop: scales from `0.4` to `1.0` with back easing (`ease: 'back.out(1.7)'`).
    *   Title text slide-up: moves vertically from `y: 40` to `y: 0` with fade.
    *   Subtitle text slide-up: moves vertically from `y: 15` to `y: 0` with fade.
*   **Supported Objects**: Predefined shield-shaped SVG icon; Title heading (`h1`); Subtitle (`p`).
*   **Supported Layouts**: Centered single-column layout.
*   **Limitations**: Hardcoded SVG icon path (cannot select custom SVG files in this template).

#### 2. Concept Diagram ([`ConceptDiagram.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/templates/ConceptDiagram.js))
*   **Intended Purpose**: Visualizes core structural relations, components, or attributes radiating from a central idea.
*   **Supported Scene Types**: Core definitions, anatomical diagrams, structural mind-maps.
*   **Configurable Properties**:
    *   `left_title` (string): Header title for bullet items column.
    *   `left_bullets` (array of strings): Narrative list items displayed as cards on the left.
    *   `central_node` (string): Text content inside the central node.
    *   `leaf_nodes` (array of strings): Radial nodes branching out.
*   **Supported Animations**:
    *   Center node pop: scales from `0` to `1` with back bounce (`ease: 'back.out(1.5)'`).
    *   Left column details: slide-in from `x: -20` to `0` with staggered bullet list reveal.
    *   Branching lines: SVG `line` elements grow dynamically from the center node to leaf coordinates (`duration: 0.6s`).
    *   Leaf cards: radial cards scale pop into final position on completion of branching line draw.
*   **Supported Objects**: Central circular node; Outer leaf cards; Connecting line vectors.
*   **Supported Layouts**:
    *   **Split Column Layout**: Left 40% reserved for bullet cards, right 55% for the semi-circular mind-map (if `left_bullets` is populated).
    *   **Full Canvas Layout**: The mind-map canvas occupies 100% of the canvas with leaf nodes placed in a full circle layout (if `left_bullets` is empty).
*   **Limitations**: Leaf node layout positions are computed automatically using trigonometry; excessive leaf node counts (> 8 leaves) will result in overlapping text labels.

#### 3. Cycle Template ([`CycleTemplate.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/templates/CycleTemplate.js))
*   **Intended Purpose**: Visualizes looping flows and circular processes (e.g., Water Cycle, Carbon Cycle).
*   **Supported Scene Types**: Step-by-step circular processes, cyclic pathways.
*   **Configurable Properties**:
    *   `title` (string): Main flow title.
    *   `stages` (array of strings or objects): Stage descriptors.
*   **Supported Animations**:
    *   Title slide-down (`y: -20` to `0`).
    *   Track draw-in: draws circular svg line track boundary stroke.
    *   Staggered stage cards: scale up from `0` to `1` along the circle circumference (`stagger: 0.15s`).
    *   Orbiting dot: A white dot orbits repeatedly along the path track.
*   **Supported Objects**: Circular track path (`circle` svg); Orbiting dot (`circle` svg); Radial stage cards.
*   **Supported Layouts**: Centered circle layout.
*   **Limitations**: Fixed coordinates on a 400x400 canvas. Orbit speed is fixed and cannot be changed via JSON properties.

#### 4. Math Derivation ([`MathDerivation.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/templates/MathDerivation.js))
*   **Intended Purpose**: Displays equations, formula derivations, or chemical formulas line-by-line.
*   **Supported Scene Types**: Mathematical proofs, derivations, formula sheets.
*   **Configurable Properties**:
    *   `title` (string): Name of the derivation.
    *   `formula` (string): Central formula (LaTeX notation).
    *   `steps` (array of strings): Line-by-line explanation steps (LaTeX notation).
*   **Supported Animations**:
    *   Title slide-down (`y: -15` to `0`).
    *   Formula board zoom pop: scale from `0.6` to `1.0` (`ease: 'back.out(1.4)'`).
    *   Step cards reveal: staggered slide-up and scale-in (`scale: 0.8`, `y: 15` to `1.0`).
*   **Supported Objects**: Main formula display board; Dynamic KaTeX container boxes; Numbered step badges.
*   **Supported Layouts**: Vertical stacked column layout.
*   **Limitations**: Strictly dependent on correct LaTeX formatting; cannot display more than 4-5 steps without causing off-screen layout clipping.

### Hyperframes Schema Specification

#### 1. Root-Level Fields
*   `lesson_title` *(Required, string)*: The main title of the lesson, used in the HTML title tag.
*   `lesson_id` *(Optional, string)*: Unique identifier in snake_case (e.g., `vl_bd18fedd`), which determines the output directory name.
*   `theme` *(Required, string)*: The global design system palette. Allowed values: `"Science"`, `"Math"`, `"History"`, `"Civics"`, `"General"`, `"indigo"`, `"gold"`, `"emerald"`, `"rose"`.
*   `layout_mode` *(Optional, string)*: Architectural layout mode of the lesson. Options: `"process"`, `"timeline"`, `"comparison"`, `"radial_breakdown"`.
*   `global_assets` *(Optional, array)*: Global resources resolved during generation.
*   `connections` *(Optional, array)*: Structural connectives for diagrams.
*   `scenes` *(Required, array)*: An ordered list of scene objects making up the video.

#### 2. Scene Object Fields
Every item inside the `scenes` array contains:
*   `scene_no` *(Required, integer)*: Sequential index of the scene (starting from 1).
*   `purpose` *(Optional, string)*: Pedagogical goal of the scene.
*   `template_id` *(Required, string)*: The visual template component to load. Allowed values:
    *   `title_slide` | `concept_diagram` | `cycle_template` | `math_derivation` | `column_comparison` | `horizontal_timeline` | `database_grid` | `venn_diagram` | `taxonomy_tree` | `cartesian_grid` | `geo_marker` | `before_after_slider` | `quiz_checkpoint` | `illustrated_scene` | `image_scene` | `general_scene`
*   `teacher_script` *(Required, string)*: Narration text to be read by the TTS voiceover, which also populates the subtitles banner in the player.
*   `durationInFrames` *(Optional, integer)*: Exact length of the scene in frames. If not provided, it is estimated by the compiler using the word count of `teacher_script` (calculated as `Math.max(5.0, words * 0.45 + 1.5) * FPS`).
*   `audio_url` *(Required/Optional, string or null)*: Relative path to the synthesized WAV audio file (e.g., `"./scene_1.wav"`). Set to `null` before audio generation.
*   `local_assets` / `assets` *(Optional, array)*: Local assets queried during generation.
*   `template_data` *(Required, object)*: Configurable properties matching the selected `template_id`.

#### 3. Template-Specific Fields (within `template_data`)

##### **title_slide**
*   `title` *(string)*: Large hero header.
*   `subtitle` *(string)*: Accompanying sub-header.

##### **concept_diagram**
*   `left_title` *(string)*: Left sidebar column title.
*   `left_bullets` *(array of strings)*: List items displayed as cards on the left.
*   `central_node` *(string)*: Label for the central circle node.
*   `leaf_nodes` *(array of strings)*: Labels for nodes extending radially from the center.

##### **cycle_template**
*   `title` *(string)*: Header for the cycle.
*   `stages` *(array of strings/objects)*: Sequence of steps forming the circle.

##### **math_derivation**
*   `title` *(string)*: Header of the step.
*   `formula` *(string)*: Large central focus formula (LaTeX formatted).
*   `steps` *(array of strings)*: List of math steps showing the proof (LaTeX formatted).

##### **column_comparison**
*   `title` *(string)*: Heading.
*   `left_column` *(object)* & `right_column` *(object)*: Each contains `header` *(string)* and `bullets` *(array of strings)*.

##### **horizontal_timeline**
*   `timeline_title` *(string)*: Heading.
*   `stages` *(array of objects)*: List of steps. Each contains `step_no` *(integer)* and `label` *(string)*.

##### **database_grid**
*   `table_title` *(string)*: Heading.
*   `headers` *(array of strings)*: Column keys.
*   `rows` *(array of arrays of strings)*: Matrix of cell strings.

##### **venn_diagram**
*   `left_title` / `right_title` *(strings)*: Entity labels.
*   `left` / `right` / `intersection` *(array of strings)*: Category list bullets.

##### **quiz_checkpoint**
*   `question` *(string)*: Quiz query.
*   `options` *(array of strings or objects)*: Selection list. If objects, must contain `text` *(string)* and `is_correct` *(boolean)*.
*   `correct_answer_index` / `correct_idx` *(integer)*: 0-indexed correct option.

##### **illustrated_scene** (Custom SVGs)
*   `canvas_color` *(string)*: CSS background color for drawing board.
*   `animation_action` *(string)*: Stagger animation style. Options: `"rise"`, `"fall"`, `"spin"`, `"scale_up"`, `"slide_left"`, `"slide_right"`, `"none"`.
*   `elements` / `svg_elements` *(array of objects)*: Raw SVG shape items. Each element must contain `type` and matching properties:
    *   `circle`: `cx` *(num)*, `cy` *(num)*, `r` *(num)*, `fill` *(str)*, `stroke` *(str)*, `stroke_width` *(num)*.
    *   `rect`: `x` *(num)*, `y` *(num)*, `width` *(num)*, `height` *(num)*, `rx` *(num)*, `fill` *(str)*, `stroke` *(str)*, `stroke_width` *(num)*.
    *   `line`: `x1` *(num)*, `y1` *(num)*, `x2` *(num)*, `y2` *(num)*, `stroke` *(str)*, `stroke_width` *(num)*.
    *   `path` / `animated_path`: `path_data` / `d` *(str)*, `dash_array` *(str)*, `fill` *(str)*, `stroke` *(str)*, `stroke_width` *(num)*.
    *   `text_overlay`: `position` *(object with x/y numbers)*, `text` *(str)*.

##### **image_scene** (Camera Zoom control)
*   `image_url` *(string)*: Path to the image file.
*   `animation_style` *(string)*: Camera pan style (e.g. `"simple_zoom"`).
*   `zoom_targets` *(array of objects)*: List of keyframes to animate camera panning and scaling. Each object contains:
    *   `at_percent` *(number, 0-100)*: Percentage timestamp along the scene's duration.
    *   `scale` *(number)*: Camera zoom level (e.g. `1.3`).
    *   `x` / `y` *(number, 0-100)*: Target coordinates to center the camera zoom on.

### Component Registry & Support Matrices

#### 1. Title Slide (`TitleSlide.js`)
*   **Purpose**: Lesson introduction slide.
*   **Supported Properties**: `title` *(string)*, `subtitle` *(string)*.
*   **Animations**: Shield card pop-in (`ease: 'back.out(1.7)'`), title text fade & slide up, subtitle text fade & slide up.
*   **SVG Support**: **Yes** (a hardcoded shield icon `<path>` inside an SVG wrapper).
*   **Image Support**: **No** (does not accept custom image files/URLs).
*   **Video Support**: **No**.
*   **Canvas Support**: **No**.
*   **HTML Support**: **Yes** (renders standard HTML container `div` and text elements `h1`, `p`).
*   **CSS Support**: **Yes** (styled using class name variables mapped to theme colors, e.g., `theme-text`, `theme-stroke`).

### What Cannot Currently Be Rendered

1.  **Dynamic Video Playback**: HTML5 `<video>` tags are not supported. Because Puppeteer takes static screenshots at specific timestamps using GSAP seek coordinates, a playing video's frames will not synchronize or align with the rendering ticks, leaving the video frozen or blank.
2.  **HTML Canvas drawing**: The templates do not contain logic to draw or capture HTML `<canvas>` buffers.
3.  **Specialized Stubs**: The following templates do not contain rendering logic and currently fall back directly to the empty header-only `GeneralScene`:
    *   `TaxonomyTree` (no tree structures drawn).
    *   `CartesianGrid` (no coordinate axis lines or functions graphed).
    *   `GeoMarker` (no geographical maps or map boundaries rendered).
    *   `BeforeAfterSlider` (no image-wipe slider transitions executed).
4.  **Iframe Embedding**: External URLs, interactive widgets, or iframe contents cannot be rendered because the headless Puppeteer browser operates offline/sandboxed, and external iframe scripts are not integrated into the main GSAP timeline.
5.  **Arbitrary Rich HTML inside Text fields**: Text strings in JSON properties (like `title` or bullet points) are escaped and rendered as plain text. Rich media tags like `<button>`, `<script>`, or custom styles placed inside titles will not be parsed or executed by the browser compiler.

### Hyperframes Animation Catalog

#### 1. Entrance Animations
*   **Slide Up & Fade**: Translates elements vertically upward (starting from `y: 15`, `y: 40`, or `y: 100` to `y: 0`) while fading opacity from `0` to `1`.
    *   *Usage*: Headline titles in `TitleSlide.js`, quiz cards in `QuizCheckpoint.js`, and illustrated elements with the `'rise'` action in `IllustratedScene.js`.
*   **Slide Down & Fade**: Translates elements vertically downward (starting from `y: -20` or `y: -100` to `y: 0`) while fading opacity from `0` to `1`.
    *   *Usage*: Headers in `CycleTemplate.js` and illustrated elements with the `'fall'` action in `IllustratedScene.js`.
*   **Slide Left & Fade**: Translates elements horizontally from the right boundary (starting from `x: 60` or `x: 150` to `x: 0`) while fading opacity from `0` to `1`.
    *   *Usage*: Illustrated elements with the `'slide_left'` action in `IllustratedScene.js`.
*   **Slide Right & Fade**: Translates elements horizontally from the left boundary (starting from `x: -50` or `x: -150` to `x: 0`) while fading opacity from `0` to `1`.
    *   *Usage*: Left columns in `ColumnComparison.js` and illustrated elements with the `'slide_right'` action in `IllustratedScene.js`.
*   **Scale Pop-In**: Expands element size from `scale: 0.4` or `scale: 0` to `scale: 1.0` with spring back-easing transitions (`ease: 'back.out(1.7)'` or `'back.out(1.5)'`).
    *   *Usage*: Icon cards in `TitleSlide.js`, mind-map central/leaf nodes in `ConceptDiagram.js`, stage cards in `CycleTemplate.js`, and item tags in `VennDiagram.js`.

#### 2. Exit Animations
*   Because video lessons are composed of discrete timeline clips layered sequentially, exit animations are handled at the scene boundaries. 
*   Standard scene objects do not have individual exit code. Instead, the containing `.scene.clip` wrapper controls visibility based on timeline playback timestamps (`data-start` and `data-duration`), making a sudden cut or fading opacity out when the timeline advances to the next scene.

#### 3. Looping Animations
*   **Orbiting Dot Loop**: A continuous circular path movement. Uses a dummy object rotation interpolation (`angle` from `-90` to `270` with `repeat: 10` and `ease: 'none'`) whose `onUpdate` tick triggers a trigonometric translation:
    $$x = 200 + 140 \cdot \cos(\theta)$$
    $$y = 200 + 140 \cdot \sin(\theta)$$
    *   *Usage*: Orbiting white dot in `CycleTemplate.js`.
*   **Floating Bobbing Loop**: A continuous vertical hover loop moving elements up and down (`yoyo: true`, `repeat: 50`) using a sine wave ease (`ease: 'sine.inOut'`).
    *   *Usage*: Helper function `window.HFAnimations.createFloatTimeline` in [`shared/animations.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/shared/animations.js).
*   **Pulse Glow Loop**: A continuous loop changing the box shadow blur radius (`yoyo: true`, `repeat: 50`) using a sine ease.
    *   *Usage*: Helper function `window.HFAnimations.pulse` in [`shared/animations.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/shared/animations.js).

#### 4. Transforms
*   **Position Translation (x, y)**: Moving objects along coordinate planes (e.g. `x: -50` in Venn diagrams or `y: 30` in grids).
*   **Scaling**: Expanding size ratios (e.g., growing circles from `scale: 0` to `scale: 1`).
*   **Rotation**: Rotating elements (e.g., 360-degree rotation of circular shape groupings with `transformOrigin: '50% 50%'` under the `'spin'` action in `IllustratedScene.js`).

#### 5. Opacity
*   Fading elements from transparent (`0`) to solid (`1`) on entrance, or dimming incorrect options to `0.3` opacity upon correct answer reveal in `QuizCheckpoint.js`.

#### 6. Camera Movement
*   **Continuous Pan/Zoom**: Smoothly scales the main viewport image card from `scale: 1.0` to `scale: 1.15` over the entire scene duration.
    *   *Usage*: Default camera style (`simple_zoom`) in `ImageScene.js`.
*   **Focal Zooming**: Custom camera path movements that pan and zoom on specified coordinate centers $(x_c, y_c)$ at target percentage durations:
    $$dx = (50 - x_c) \cdot 5\text{px}$$
    $$dy = (50 - y_c) \cdot 5\text{px}$$
    *   *Usage*: Custom `zoom_targets` lists in `ImageScene.js`.

#### 7. Path / Stroke Animations
*   **SVG Dash Offset Draw-In**: Draws stroke line vectors from $0\%$ to $100\%$. The compiler calculates the total path length $L$ (using `getTotalLength()` or $L = 2\pi r$ for circles), sets `strokeDasharray = L` and `strokeDashoffset = L`, and animates `strokeDashoffset` to `0` with `ease: 'power2.inOut'`.
    *   *Usage*: Connector line drawings in `ConceptDiagram.js`, progress tracks in `HorizontalTimeline.js`, and orbit tracks in `CycleTemplate.js`.

### How Animations are Attached to Scene Objects

The engine links GSAP animations to rendered HTML elements through the following four-step mechanism:

```mermaid
graph TD
    A["1. Template compilation exports dynamic GSAP script string containing selectors e.g. '#opt-idx'"] --> B["2. run-storyboard.js creates local sceneTl = gsap.timeline() for each scene"]
    B --> C["3. Template string is appended into sceneTl context inside index.html"]
    C --> D["4. sceneTl is added to master timeline: mainTimeline.add(sceneTl, scene.start)"]
    D --> E["5. Headless Puppeteer engine seeks through mainTimeline frame-by-frame to render frame captures"]
```

1.  **Script Generation**: Every template exports an `animate(sId, data, theme, sceneDuration)` function. This function returns a string block of JavaScript code containing GSAP tween instructions targeting specific DOM selectors (e.g. `sceneTl.fromTo('#quiz-card-${sId}', ...)`, where `${sId}` resolves to the scene number).
2.  **Local Timeline Creation**: During compilation in [`run-storyboard.js`](file:///c:/Users/home/Desktop/CG-DEV/CD-APP1FB/hyperframes_test_app/run-storyboard.js), the compiler loops through the scenes, instantiates a local GSAP timeline for each (`const sceneTl = gsap.timeline()`), and appends the script string returned by the template's `animate()` function.
3.  **Master Timeline Integration**: The compiler mounts every scene timeline on the master timeline at its starting offset:
    ```javascript
    mainTimeline.add(sceneTl, scene.start);
    ```
4.  **Render Playback Seek**: When the generated page is opened by Puppeteer during video export, the compiler controls playback by seeking through the master timeline (`window.__timelines["root"]`). GSAP translates these seek offsets directly into inline styling, transform matrices, and coordinate updates on the target DOM elements.

| **Illustrations** | **Yes** | Rendered as custom coordinate vectors within `IllustratedScene.js` dynamically by mapping mathematical coordinates to SVG components. |
| **Lottie** | **No** | Not supported. There are no Lottie libraries (like `lottie-web`) or parser integrations in the codebase. |
| **Canvas** | **No** | Not supported. The templates do not construct `<canvas>` elements, and there is no drawing context logic. |
| **Three.js** | **No** | Not supported. The compiler renders 2D CSS and SVG layers. There is no WebGL setup or Three.js camera rendering. |
| **Video** | **No** | Not supported. Because Puppeteer captures screenshots by seeking the GSAP timeline step-by-step, native video playback will not align with GSAP seek offsets, causing video loops to freeze, stutter, or drop entirely. |
| **GIF** | **No** *(Partially)* | While a GIF can be loaded in an `<img>` tag, its internal animation playback loop operates independently of GSAP. During frame seek capture, the GIF frame will not synchronize with the timeline playhead, leading to speed mismatches or static loops. |

### How Assets are Referenced

Assets are referenced dynamically inside files using two methods:

#### 1. In `lesson.json`
References are formatted inside the JSON structure using relative paths or web URLs:
*   **Audio WAVs**: Point to local assets relative to the lesson root (e.g. `"audio_url": "./scene_1.wav"`).
*   **Images**: Reference absolute HTTP/HTTPS web endpoints (e.g. `"image_url": "https://upload.wikimedia.org/wikipedia/commons/e/e4/Water_molecule_polarity.png"`).

#### 2. In `index.html` (Compiled Layout)
The template compilation translates the JSON references directly into HTML:
*   **Audio Elements**: Mapped to native audio tags specifying the scene starting frames:
    ```html
    <audio class="clip" data-start="19.5" data-duration="18.6" src="./scene_2.wav" id="audio-scene-2"></audio>
    ```
*   **Image Elements**: Linked to images using source attributes:
    ```html
    <img src="https://upload.wikimedia.org/..." class="scene-image" id="img-el-3" />
    ```
*   **Shared Scripts**: Referenced using local relative links:
    ```html
    <script src="./shared/theme.js"></script>
    <script src="./shared/animations.js"></script>
    ```

```javascript
module.exports = {
  render: (sId, data) => {
    const hasBullets = data.left_bullets && data.left_bullets.length > 0;
    return `
      <div class="concept-diagram-container" id="concept-diagram-${sId}">
        ${hasBullets ? `
        <div class="left-bullets-col">
          <h2 class="theme-text" id="cd-left-title-${sId}" style="font-size: 38px; font-weight: 800; margin-bottom: 24px; letter-spacing: -1px;">${data.left_title || ''}</h2>
          <div style="display: flex; flex-direction: column; gap: 16px;" id="cd-bullets-list-${sId}">
            ${data.left_bullets.map((b, bIdx) => `<div class="bullet-card theme-card-bg theme-card-border" id="cd-bullet-${sId}-${bIdx}">${b}</div>`).join('')}
          </div>
        </div>
        ` : ''}
        
        <div class="mindmap-canvas" style="position: relative; width: ${hasBullets ? '55%' : '100%'}; height: 100%; display: flex; align-items: center; justify-content: center;">
          <svg viewBox="0 0 1280 720" style="position: absolute; width: 1280px; height: 720px; top: 0; left: 0; z-index: 2; pointer-events: none;">
            <g id="cd-lines-group-${sId}"></g>
          </svg>
          <div class="center-node theme-accent-bg" id="cd-center-${sId}" style="color: #090d16;">${data.central_node || ''}</div>
          <div id="cd-leaves-group-${sId}">
            ${(data.leaf_nodes || []).map((node, nIdx) => `<div class="leaf-node theme-card-border" id="cd-leaf-${sId}-${nIdx}">${node}</div>`).join('')}
          </div>
        </div>
      </div>
    `;
  },
  animate: (sId, data) => {
    const hasBullets = data.left_bullets && data.left_bullets.length > 0;
    const centerX = hasBullets ? 900 : 640;
    const centerY = 360;
    const radius = hasBullets ? 190 : 270;
    const totalLeaves = (data.leaf_nodes || []).length;
    
    return `
      sceneTl.fromTo('#cd-center-${sId}', { scale: 0 }, { scale: 1, duration: 0.5, ease: 'back.out(1.5)' });
      
      ${hasBullets ? `
        sceneTl.fromTo('#cd-left-title-${sId}', { opacity: 0, x: -20 }, { opacity: 1, x: 0, duration: 0.4 }, 0.2);
        sceneTl.fromTo('#cd-bullets-list-${sId} .bullet-card', { opacity: 0, y: 15 }, { opacity: 1, y: 0, stagger: 0.15, duration: 0.4 }, 0.3);
      ` : ''}

      const linesGroup_${sId} = document.getElementById('cd-lines-group-${sId}');
      const leafNodesData_${sId} = ${JSON.stringify(data.leaf_nodes || [])};
      
      leafNodesData_${sId}.forEach((node, idx) => {
        const total = leafNodesData_${sId}.length;
        let angle = 0;
        if (${hasBullets}) {
          angle = -Math.PI / 3 + (idx * (2 * Math.PI / 3)) / Math.max(1, total - 1);
        } else {
          const leftNodes = [];
          const rightNodes = [];
          for (let i = 0; i < total; i++) {
            if (i % 2 === 0) rightNodes.push(i);
            else leftNodes.push(i);
          }
          if (idx % 2 === 0) {
            const k = rightNodes.indexOf(idx);
            const M = rightNodes.length;
            angle = -Math.PI / 4.5 + (k * (2 * Math.PI / 4.5)) / Math.max(1, M - 1);
          } else {
            const k = leftNodes.indexOf(idx);
            const L = leftNodes.length;
            angle = Math.PI - Math.PI / 4.5 + (k * (2 * Math.PI / 4.5)) / Math.max(1, L - 1);
          }
        }
        
        const x2 = ${centerX} + ${radius} * Math.cos(angle);
        const y2 = ${centerY} + ${radius} * Math.sin(angle);
        
        const lineEl = document.createElementNS('http://www.w3.org/2000/svg', 'line');
        lineEl.setAttribute('x1', ${centerX});
        lineEl.setAttribute('y1', ${centerY});
        lineEl.setAttribute('x2', ${centerX});
        lineEl.setAttribute('y2', ${centerY});
        lineEl.setAttribute('stroke', theme.accentColor);
        lineEl.setAttribute('stroke-width', '3.5');
        lineEl.setAttribute('stroke-linecap', 'round');
        lineEl.style.filter = 'drop-shadow(0 0 4px ' + theme.accentColor + ')';
        lineEl.style.opacity = '0.75';
        linesGroup_${sId}.appendChild(lineEl);

        const leafNode = document.getElementById('cd-leaf-${sId}-' + idx);
        if (leafNode) {
          leafNode.style.left = x2 + 'px';
          leafNode.style.top = y2 + 'px';
          leafNode.style.transform = 'translate(-50%, -50%) scale(0)';
        }

        sceneTl.to(lineEl, {
          attr: { x2: x2, y2: y2 },
          duration: 0.6,
          ease: 'power2.out'
        }, 0.5 + idx * 0.05);

        if (leafNode) {
          sceneTl.to(leafNode, {
            transform: 'translate(-50%, -50%) scale(1)',
            duration: 0.4,
            ease: 'back.out(1.5)'
          }, 0.8 + idx * 0.05);
        }
      });
    `;
  }
};
```
